# 导出功能性能优化计划

## 任务目标
基于用户反馈，优化导出报表功能的性能和可用性：

### 高优先级问题
1. **Git记录获取开关**：提供开关让用户可以选择是否包含提交信息
2. **提交历史获取范围优化**：只获取筛选后文件清单的提交历史，避免全仓库扫描

### 中优先级问题  
3. **多线程并行处理**：实现文件级别的并行提交历史获取

## 实施计划

### 第一阶段：Git记录获取开关功能
- [ ] 修改前端MultiRepoExportDialog添加"包含提交信息"开关
- [ ] 修改后端MultiRepoExportService支持条件性跳过提交信息获取
- [ ] 更新DiffMatrixFilterCriteria处理逻辑
- [ ] 测试开关功能

### 第二阶段：提交历史获取范围优化
- [ ] 优化CommitInfoAggregatorService只处理筛选后的文件
- [ ] 改进GitCommitHistoryService的批量获取逻辑
- [ ] 添加文件级别的条件判断
- [ ] 测试范围优化效果

### 第三阶段：多线程并行处理
- [ ] 添加线程池配置
- [ ] 实现文件级别的并行提交历史获取
- [ ] Oracle和Gauss仓库并行化处理

### 第四阶段：测试和文档
- [ ] 性能基准测试

## 预期效果

### 性能提升
- 导出时间减少50-70%
- 内存使用优化30-50%
- 并发处理能力提升3-5倍

### 用户体验
- 提供明确的开关控制
- 更快的响应速度
- 更好的进度反馈
