# 导出报表中提交记录获取流程图

## 1. 整体流程图

```mermaid
graph TD
    A[用户开启包含提交记录] --> B[前端构建导出请求]
    B --> C[发送POST请求到后端]
    C --> D[MultiRepoExportService.export]
    D --> E{检查includeCommitInfo}
    E -->|false| F[跳过提交信息获取]
    E -->|true| G[执行完整提交信息获取]
    G --> H[遍历每个仓库]
    H --> I[获取扫描报告]
    I --> J[组装差异数据]
    J --> K[enrichRowsWithCommitInfo]
    K --> L[aggregateAuthorStats]
    L --> M[aggregateFileCommitDetails]
    M --> N[生成导出结果]
    F --> N
    N --> O[返回给前端]
    O --> P[前端下载文件]
```

## 2. 提交信息获取详细流程

```mermaid
sequenceDiagram
    participant Frontend as 前端
    participant Controller as ScanController
    participant ExportService as MultiRepoExportService
    participant CommitAggregator as CommitInfoAggregatorService
    participant GitService as GitCommitHistoryService
    participant JGit as JGit API
    participant Cache as 缓存

    Frontend->>Controller: POST /api/scan/report/aggregate
    Controller->>ExportService: export(request)
    
    loop 每个仓库
        ExportService->>ExportService: resolveReport(selection)
        ExportService->>ExportService: enrichRowsWithCommitInfo()
        
        par Oracle仓库
            ExportService->>CommitAggregator: enrichWithCommitInfo(row, oracleRepo, gaussRepo)
            CommitAggregator->>GitService: getFileCommitHistory(filePath, oracleRepo, null)
            GitService->>Cache: 检查缓存
            alt 缓存命中
                Cache-->>GitService: 返回缓存数据
            else 缓存未命中
                GitService->>JGit: git.log().addPath(filePath).call()
                JGit-->>GitService: 返回RevCommit列表
                GitService->>GitService: convertToGitCommitInfoDTO()
                GitService->>Cache: 存入缓存
            end
            GitService-->>CommitAggregator: 返回Oracle提交列表
        and Gauss仓库
            CommitAggregator->>GitService: getFileCommitHistory(filePath, null, gaussRepo)
            GitService->>JGit: git.log().addPath(filePath).call()
            JGit-->>GitService: 返回RevCommit列表
            GitService->>GitService: convertToGitCommitInfoDTO()
            GitService-->>CommitAggregator: 返回Gauss提交列表
        end
        
        CommitAggregator->>CommitAggregator: 处理提交信息并设置到DiffMatrixRow
        CommitAggregator-->>ExportService: 返回丰富后的行数据
    end
    
    ExportService->>ExportService: aggregateAuthorStats()
    ExportService->>ExportService: aggregateFileCommitDetails()
    ExportService-->>Controller: 返回MultiRepoExportResult
    Controller-->>Frontend: 返回导出文件
```

## 6. 错误处理流程

```mermaid
graph TD
    A[开始获取提交信息] --> B[检查仓库配置]
    B --> C{配置有效?}
    
    C -->|否| D[记录警告日志]
    D --> E[返回空结果]
    
    C -->|是| F[打开Git仓库]
    F --> G{仓库打开成功?}
    
    G -->|否| H[记录错误日志]
    H --> I[返回空结果]
    
    G -->|是| J[执行Git log命令]
    J --> K{Git命令成功?}
    
    K -->|否| L[记录错误日志]
    L --> M[返回空结果]
    
    K -->|是| N[解析提交数据]
    N --> O{解析成功?}
    
    O -->|否| P[记录警告日志]
    P --> Q[返回部分结果]
    
    O -->|是| R[返回完整结果]
    
    E --> S[继续处理]
    I --> S
    M --> S
    Q --> S
    R --> S
```

## 7. 数据结构关系图

```mermaid
classDiagram
    class MultiRepoExportRequest {
        +List~RepoSelection~ repos
        +DiffMatrixFilterCriteria filterCriteria
        +String format
    }
    
    class DiffMatrixFilterCriteria {
        +boolean includeCommitInfo
        +String authorTypeFilter
        +List~String~ authorFilters
        +Instant timeFrom
        +Instant timeTo
    }
    
    class DiffMatrixRow {
        +String filePath
        +String lastOracleAuthor
        +Instant lastOracleCommitTime
        +String lastOracleCommitMessage
        +Integer oracleCommitCount
        +Boolean hasOracleCommits
        +String lastGaussAuthor
        +Instant lastGaussCommitTime
        +String lastGaussCommitMessage
        +Integer gaussCommitCount
        +Boolean hasGaussCommits
    }
    
    class FileCommitDetail {
        +String filePath
        +String repoSource
        +String commitHash
        +String authorName
        +String authorEmail
        +Instant commitTime
        +String commitMessage
        +String commitType
        +Integer linesAdded
        +Integer linesRemoved
    }
    
    class CommitAuthorStats {
        +String authorName
        +String authorEmail
        +Integer oracleCommitCount
        +Integer gaussCommitCount
        +Integer totalCommitCount
        +String authorType
        +Double activityScore
        +Set~String~ affectedFiles
    }
    
    class FileCommitHistoryDTO {
        +String filePath
        +List~GitCommitInfoDTO~ oracleCommits
        +List~GitCommitInfoDTO~ gaussCommits
        +Integer totalCount
        +Boolean hasOracleCommits
        +Boolean hasGaussCommits
    }
    
    MultiRepoExportRequest --> DiffMatrixFilterCriteria
    DiffMatrixFilterCriteria --> DiffMatrixRow
    DiffMatrixRow --> FileCommitDetail
    DiffMatrixRow --> CommitAuthorStats
    FileCommitHistoryDTO --> DiffMatrixRow
```

## 8. 缓存策略流程

```mermaid
graph TD
    A[获取文件提交历史请求] --> B[生成缓存键]
    B --> C[filePath + oracleRepoPath + gaussRepoPath]
    C --> D[查询Redis缓存]
    D --> E{缓存存在?}
    
    E -->|是| F[返回缓存数据]
    E -->|否| G[执行Git操作]
    
    G --> H[打开Git仓库]
    H --> I[执行git log]
    I --> J[解析提交数据]
    J --> K[转换为DTO]
    K --> L[存入缓存]
    L --> M[设置过期时间]
    M --> N[返回数据]
    
    F --> O[记录缓存命中]
    N --> P[记录缓存未命中]
    O --> Q[返回结果]
    P --> Q
```
