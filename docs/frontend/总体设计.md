## **二、核心页面说明**

### **1. RepoConfigPage.vue**

配置对比仓库路径与分支版本。

**主要内容**

* Oracle 仓库路径（`oracleRepoPath`）
* Gauss 仓库路径（`gaussRepoPath`）
* Oracle 分支：`o1`（源）`o2`（目标）
* Gauss 分支：`g1`（源）`g2`（目标）

**操作**

* 保存配置 → `POST /api/config/save`
* 测试连接 → `GET /api/config/test`

**组件**

* `<RepoConfigCard>` 用于仓库路径输入
* `<BranchConfigCard>` 用于分支选择

---

### **2. DashboardPage.vue**

展示 ΔO（o1→o2）与 ΔG（g1→g2）的差异统计。

**主要内容**

* 仓库信息卡：展示仓库路径、分支名、提交统计
* ΔO vs ΔG 矩阵图（`<DiffMatrix>`）
* 概览指标：新增、修改、删除文件数、一致率

**交互**

* 点击矩阵单元格 → 跳转至 FileDiffPage 并传递参数 `{ filePath, oracleDelta, gaussDelta }`
* “刷新”按钮 → 调用 `GET /api/diff/scan`

---

### **3. FileDiffPage.vue**

展示四版本差异与迁移操作。

**展示模式**

| 模式       | 左侧 | 右侧   |
| -------- | -- | ---- |
| ΔO       | o1 | o2   |
| ΔG       | g1 | g2   |
| ΔO vs ΔG | ΔO | ΔG   |
| 迁移结果     | ΔO | 迁移产出 |

**主要功能**

* **Monaco Diff Viewer**：支持 4 种模式切换
* **操作按钮**：

  * 生成 → `POST /api/migrate/generate`
  * 撤销 → `POST /api/migrate/revert`
  * 应用 → `POST /api/migrate/apply`
* **文件信息区**：文件路径、模块、变更统计
* **DiffToolbar**：模式切换、上下文折叠、导出

**状态流**

* 页面加载 → 调用 `/api/diff/detail`
* 生成 → 更新状态并追加迁移结果视图
* 应用或撤销 → 写入日志模块

---

### **4. LogsPage.vue**

显示扫描、生成、应用、撤销等操作日志。

**字段**

* 操作ID、类型（Scan/Generate/Apply/Revert）、文件路径、操作者、时间、耗时、状态。

**接口**

* `GET /api/logs/list`
* `GET /api/logs/detail/:id`

**组件**

* `<LogTable>`：分页表格，行展开显示详细日志。

---

### **5. SettingsPage.vue**

全局行为控制。

**配置项**

* 自动应用（bool）
* 默认对比模式（枚举：ΔO、ΔG、对比、迁移结果）
* 忽略空行/注释（bool）
* 主题（light/dark）
* 导入/导出配置按钮

**接口**

* `GET /api/settings`
* `POST /api/settings/update`

## **三、静态 Mock 数据的加载方式**

在开发时，修改 Axios 的 `request.js` 文件以动态使用 Mock 数据：

#### 修改 `request.js`：
```js
import configMock from '../mock/configMock.js';
import diffMock from '../mock/diffMock.js';
import logsMock from '../mock/logsMock.js';
import settingsMock from '../mock/settingsMock.js';

const useMockData = true; // 控制是否使用 Mock 数据

export default function request(method, url, data = null) {
  if (useMockData) {
    switch (url) {
      case '/api/config/save':
        return Promise.resolve(configMock);
      case '/api/config/test':
        return Promise.resolve({ status: 'success', message: '连接测试成功' });
      case '/api/diff/scan':
        return Promise.resolve(diffMock.diffMatrix);
      case '/api/diff/detail':
        return Promise.resolve(diffMock.currentFile);
      case '/api/logs/list':
        return Promise.resolve(logsMock.logs);
      case '/api/settings':
        return Promise.resolve(settingsMock);
      case '/api/settings/update':
        return Promise.resolve({ status: 'success', message: '配置更新成功' });
      default:
        return Promise.reject(new Error('Unknown API endpoint.'));
    }
  }

  // 实际后端请求逻辑
  return axios({
    method,
    url,
    data,
  });
}
```

#### 切换 Mock 数据：
- 设置 `useMockData` 为 `true` 开启模拟数据模式。
- 修改静态模块 (如 `configMock`) 内容即能实时更新页面展示。
