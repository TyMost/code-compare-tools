# 导出报表功能优化 - 新Excel双Sheet结构验证报告

## 概述

本报告验证了新的Excel导出双Sheet结构，该结构专门为呈现 `2025-11-01T00:00:00Z` 到 `2025-12-02T23:59:59Z` 时间范围内的提交信息而设计。

## 实现的功能

### 1. 双Sheet结构设计

#### Sheet1: 文件级覆盖信息
- **目的**: 提供文件级别的覆盖率概览
- **包含字段**:
  - 文件路径
  - 覆盖率状态
  - Oracle/Gauss代码行数变更
  - 最新提交信息（作者、时间、消息）
  - 提交次数统计

#### Sheet2: 详细提交信息
- **目的**: 列出时间范围内的所有提交记录
- **包含字段**:
  - 文件路径
  - 仓库来源（Oracle/Gauss）
  - 提交哈希
  - 作者信息（姓名、邮箱）
  - 提交时间
  - 提交消息
  - 提交类型（feature/bugfix/refactor/other）
  - 变更类型（MODIFY/ADD/DELETE）
  - 代码行数变更（增加/删除）

### 2. 数据模型扩展

#### 新增 FileCommitDetail 类
```java
public class FileCommitDetail {
    private String filePath;           // 文件路径
    private String repoSource;         // 仓库来源
    private String commitHash;         // 提交哈希
    private String authorName;         // 作者姓名
    private String authorEmail;        // 作者邮箱
    private Instant commitTime;        // 提交时间
    private String commitMessage;      // 提交消息
    private String commitType;         // 提交类型
    private String changeType;         // 变更类型
    private Integer linesAdded;        // 增加行数
    private Integer linesRemoved;      // 删除行数
    private Boolean inTimeRange;       // 是否在时间范围内
}
```

### 3. Excel格式优化

#### 样式设置
- **标题行**: 加粗、背景色、白色字体
- **日期格式**: 统一为 `yyyy-MM-dd HH:mm:ss`
- **列宽**: 自适应调整，确保内容完整显示
- **冻结窗格**: 冻结标题行，便于浏览大量数据
