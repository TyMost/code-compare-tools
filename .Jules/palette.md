## 2024-07-26 - Adding Accessibility Labels to Dynamic Interactive Controls in Lists

**Learning:** When auditing Vue components for accessibility, dynamic lists rendered with `v-for` that contain interactive controls frequently lack proper labels. Native `<input>` elements rendered via custom components like `<el-input>`, and generic icon-only buttons like `<el-button>` (e.g., using `el-icon-delete`), inside these lists become inaccessible without unique descriptors. Screen readers and users relying on tooltips cannot differentiate between multiple identical controls generated by the loop. While `aria-label` is crucial, `title` can also serve as a viable accessibility fallback.

**Action:** Always ensure that generic interactive elements (inputs and icon-only buttons) within `v-for` loops explicitly include context-specific, localized `aria-label` and `title` attributes. Use template literals (e.g., `` :aria-label="`删除规则 ${index + 1}`" ``) to append the loop index or distinct item content, ensuring each element has a unique and descriptive label.
