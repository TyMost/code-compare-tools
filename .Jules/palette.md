## 2024-11-20 - Adding Unique Accessibility Labels in Vue `v-for` Loops
**Learning:** When creating dynamic lists with interactive elements (like inputs and buttons) using Vue's `v-for` directive, it is crucial to ensure that each generated element has a unique and context-specific label. In Vue 2 with Element UI, adding standard HTML attributes like `aria-label` or `title` to custom components directly in a loop requires making them unique (e.g., using template literals with the loop `index`) so that screen readers and tooltips can effectively distinguish between the multiple identical elements generated by the loop.
**Action:** Always append dynamic content or the loop index (e.g., `:aria-label="\`删除规则 ${index + 1}\`"`) when applying `aria-label` and `title` to interactive controls inside a `v-for` loop.
