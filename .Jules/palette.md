## 2026-09-05 - Unique Accessibility Labels in Dynamic Vue Lists
**Learning:** Interactive elements within dynamic lists rendered with `v-for` in Vue frequently lack proper accessibility attributes. Specifically, input fields and generic icon-only buttons (like Element UI's `el-icon-delete`) within these loops must explicitly include context-specific, localized `aria-label` and `title` attributes. Adding these attributes directly to custom components like `<el-input>` may not always pass down automatically to native elements, but `title` often works well as a fallback. For Vue `v-for` lists, you must ensure uniqueness by using template literals that append the loop index or distinct item content (e.g., `:aria-label="\`删除规则 ${index + 1}\`"`) to aid screen reader distinction.
**Action:** When auditing or adding interactive controls to Vue `v-for` lists, always ensure they are given dynamically generated, unique, and localized `aria-label` and `title` attributes based on the loop index or item content.
