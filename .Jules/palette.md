## 2026-09-10 - Adding Context to Icon-Only Action Buttons in Dynamic Lists
**Learning:** Icon-only action buttons inside dynamic `v-for` lists are a common pattern (e.g. `DiffMatrixFilters.vue`), but lack context for screen readers when they are not uniquely identifiable. Standard Element UI attributes like `aria-label` may not pass down as expected on some custom elements, but providing descriptive string literals for both `aria-label` and `title` ensures both screen reader and mouse hover tooltips work appropriately. Incorporating dynamic content like index loops (e.g., `` `删除规则 ${index + 1}` ``) guarantees that each button is distinguishable by its specific row function.
**Action:** When auditing Vue component iterables (e.g. `v-for`), explicitly check for interactive elements, particularly icon-only buttons, to ensure they have loop-contextual, localized `aria-label` and `title` attributes (e.g. `删除规则`).
