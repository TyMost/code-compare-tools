## 2024-07-20 - Adding Accessibility Labels in dynamic v-for lists
**Learning:** When using dynamic lists (`v-for`) that render interactive components like inputs or icon-only buttons (e.g., `el-icon-delete`), screen readers often cannot identify context because the generic items lack individualized labels. Moreover, with UI libraries like Element UI, standard `aria-label`s on custom components might not propagate automatically to the underlying native `<input>` or `<button>`. Using the `title` attribute works as an effective fallback for both screen readers and tooltips in these situations.
**Action:** When creating forms or lists containing dynamic inputs and icon-only actions, ensure both `aria-label` and `title` attributes are applied. Always use localized text (e.g., "排除规则" and "删除规则") to maintain consistency with the rest of the application's interface.
