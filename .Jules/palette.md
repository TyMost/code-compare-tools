## 2024-07-22 - Explicit Accessibility in Element UI Dynamic Lists
**Learning:** In Vue 2 with Element UI, dynamic lists rendered with `v-for` that contain interactive controls frequently lack proper accessibility labels. Specifically, input fields (`<el-input>`) and generic icon-only buttons (like Element UI's `el-icon-delete`) within these loops must explicitly include context-specific, localized `aria-label` and `title` attributes. Furthermore, standard HTML attributes like `aria-label` added directly to custom components like `<el-input>` may not be passed down automatically to the native underlying `<input>` element, but the `title` attribute successfully propagates down and serves as a viable fallback for screen readers and tooltips.
**Action:** When adding or auditing dynamic arrays of input controls and icon buttons, always apply explicit, localized `title` and `aria-label` attributes to ensure they are properly accessible, accommodating Element UI's prop passing limitations.
