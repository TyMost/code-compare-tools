## 2024-08-09 - Accessibility in Vue v-for lists with Element UI
**Learning:** When using `v-for` loops to render lists of interactive elements (like inputs and delete buttons) in Vue with Element UI, it is critical to use template literals (e.g., `:aria-label="\`删除规则 ${index + 1}\`"`) to ensure each element has a unique label for screen readers. Furthermore, because standard HTML attributes like `aria-label` may not propagate automatically down to the native input element within custom Vue 2 components like `<el-input>`, providing a `title` attribute acts as a reliable fallback for tooltips and accessibility.
**Action:** Always verify that elements in dynamic `v-for` lists are uniquely labeled, and apply both `:aria-label` and `:title` to custom Element UI components to guarantee proper accessibility fallback mechanisms.
