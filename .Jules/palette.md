## 2026-09-07 - Add accessibility attributes to dynamically generated input elements

**Learning:** When adding `aria-label` or `title` attributes inside Vue `v-for` loops (like in a dynamic exclusion pattern list), it is important to ensure uniqueness by using template literals that append the loop index or distinct item content (e.g., `:aria-label="\`删除排除规则 ${index + 1}\`"` and `:title="\`排除规则 ${index + 1}\`"`). This aids screen reader distinction, especially for icon-only buttons or ambiguous generic `<el-input>` components. Also, Element UI's `<el-input>` sometimes doesn't pass `aria-label` down to the native input element cleanly, but `title` is successfully passed.
**Action:** When auditing dynamic lists rendered with `v-for` containing interactive controls (like Element UI's `el-icon-delete` or generic input text boxes), explicitly verify and add context-specific, localized `aria-label` and `title` attributes that include the loop index for uniqueness. Use `title` as a fallback for custom components that drop `aria-label`.
