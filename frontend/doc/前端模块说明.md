# 代码迁移对比前端模块说明

> **框架基线**：Vue 2.7 + Vue Router 3 + Vuex 3 + Element UI + Axios + ECharts + Monaco Editor。  
> **适配对象**：`前端模块设计.md` 与《后端接口草案.md》中定义的 REST 接口。

---

## 1. 页面结构总览

| 页面 | 模块分区 | 组件职责 | 主要数据来源 |
|------|----------|----------|--------------|
| Dashboard - Project Overview | 顶部标题区 | 显示当前项目上下文（项目名、路径） | `GET /api/v1/migration/overview` |
| | 数据看板区 | 环形图：代码迁移类别占比；Git 行数对比卡 | `codeCategoryStats`、`gitSourceChangedLines`、`gitTargetChangedLines`、`diffEngine` |
| | 批量操作与筛选区 | 批量处理、分类筛选 | `codeCategoryStats`、批量接口 |
| | 文件与代码块差异列表区 | 可分组列表、分页、跳转详情 | `GET /api/v1/migration/code-blocks` |
| Detail Page - Code Diff | 顶部信息栏 | 返回导航、文件路径、行号范围 | `GET /api/v1/migration/code-blocks/{id}` |
| | 核心操作区 | 单条迁移操作（生成/应用/忽略） | `POST /code-blocks/{id}/generate` 等 |
| | 代码比对区 | Side-by-Side Diff 展示旧/新代码 | 同上接口返回 `codeBefore` / `codeAfter` |
| | 生成结果显示区 | 预留 AI 生成结果区块，默认隐藏 | 预留 `GET .../ai-suggestion` |

## 2. 页面一：Dashboard 模块拆解

### 2.1 顶部标题区（`components/dashboard/DashboardHeader.vue`）
- **输入参数**：
  - `oldProjectPath`、`newProjectPath`、`lastSyncedAt`
  - 由 `overview` 接口响应映射。
- **交互说明**：
  - 固定顶部展示；未来可扩展刷新按钮，触发 `fetchOverview`。

### 2.2 数据看板区

| 子模块 | 组件 | 职责 | 依赖接口字段 |
|--------|------|------|--------------|
| 代码迁移类别占比图 | `components/dashboard/CategoryDonut.vue` | 渲染环形图，悬停显示百分比与行数 | `codeCategoryStats` |
| Git 变动行数对比卡 | `components/dashboard/GitChangeSummaryCard.vue` | 展示源/目标仓变动行数对比 | `gitSourceChangedLines`、`gitTargetChangedLines`、`diffEngine` |

> **图表统一封装**：在 `components/charts` 下提供 `EChartsWrapper.vue` 用于初始化、响应式处理。

### 2.3 批量操作与筛选区
- **组件结构**：`components/dashboard/BatchToolbar.vue`
- **核心 props**：
  - `selectedIds: string[]`
  - `categoryOptions: Array<{ value: string; label: string; color: string }>`
- **发起请求**：
  - `POST /code-blocks/generate`
  - `POST /code-blocks/apply`
  - `POST /code-blocks/ignore`
- **事件**：
  - `@action-success`：通知父组件刷新列表 & 概览数据。
  - `@filter-change(categoryValues: string[])`：更新列表查询参数。

### 2.4 文件与代码块差异列表区
- **组件结构**：`views/dashboard/CodeBlockTable.vue`
- **功能点**：
  - 以文件路径分组：前端对 `GET /code-blocks` 的返回按 `filePath` 分桶。
  - 支持分页：使用 Element UI `el-pagination`，与接口 `page`、`size` 参数联动。
  - 列表列：
    - Checkbox（支持全选）：维护 `selectedIds`。
    - 代码块摘要：`filePath`、`lineRange`、`codeSnippet`。
    - 分类标签：展示标签文案，颜色由 `categoryOptions` 匹配。
    - 操作列：`查看详情`，跳转 `/code-block/:id`。
- **分类联动**：
  - 批量操作成功后刷新当前页；若为空则退回上一页。

## 3. 页面二：详情页模块拆解

### 3.1 顶部信息栏（`components/detail/DetailHeader.vue`）
- Props：`filePath`、`lineRange`、`categories: Array<{ label: string; color: string; value: string }>`。
- 展示：行号旁以标签形式呈现分类文案，颜色与 `categoryOptions` 对齐。
- 操作：`返回列表` 按钮触发路由 `this.$router.back()` 或返回 Dashboard。

### 3.2 核心操作区（`components/detail/ActionBar.vue`）
- 按钮集合：
  - `生成` → 调用 `POST /code-blocks/{id}/generate`
  - `应用` → 调用 `POST /code-blocks/{id}/apply`
  - `忽略` → 调用 `POST /code-blocks/{id}/ignore`
- **按钮状态**：
  - 根据后端返回的 `status` key 控制禁用逻辑，避免重复执行同一操作。
  - 请求期间显示 `loading`。
- **事件**：
  - 成功后触发 `@reload`，详情页重新获取数据 & 通知 Dashboard 重载。

### 3.3 代码比对区（`components/detail/CodeDiffViewer.vue`）
- **技术选型**：
  - 使用 `Monaco Editor` + `diff-editor` 模式。
  - 行号同步；`oldCode`、`newCode` 由详情接口返回。
- **配色说明**：
  - 分类标签统一由顶部信息栏展示，Diff 区域保持纯代码视图。

### 3.4 生成结果显示区（预留）
- `components/detail/AISuggestionPanel.vue`
- 默认 `v-if="config.enableAI"`，配置存放于 `src/config/featureFlags.js`。
- 未来接入 `GET /code-blocks/{id}/ai-suggestion` 后渲染。

## 4. 跨页面共享模块

### 4.1 路由（`src/router/index.js`）
- `/dashboard`：默认首页。
- `/code-block/:id`：详情页。
- 未来可扩展 `/settings` 等页面。

### 4.2 数据管理（`src/store/modules/migration.js`）

| State | 描述 | 初始化方式 |
|-------|------|------------|
| `overview` | Dashboard 概览数据 | `fetchOverview` |
| `filters` | 列表筛选条件（categories，多选） | 路由 query ↔ Vuex 同步 |
| `pagination` | 页码与尺寸 | 接口返回的 `page`, `size`, `total` |
| `selectedIds` | 批量选中记录 | 由列表组件维护并同步到 Vuex |

> 保持前后端解耦：所有标签文案、颜色均使用接口返回值，不在 store 内硬编码。

### 4.3 接口层（见 5.2 节）
- 统一封装 `Axios` 实例，处理基础路径 `/api/v1/migration`、错误拦截、loading。

### 4.4 公共常量与工具
- `src/constants`：仅保留分类颜色的兜底映射（如未知标签），其余依赖后端返回。
- `src/utils/date.js`：时间格式化，用于显示 `createdAt`、`updatedAt`。

## 5. 与后端接口的对照关系

### 5.1 请求/响应字段适配

| 场景 | 接口 | 前端模块 | 说明 |
|------|------|----------|------|
| 加载 Dashboard | `GET /overview` | `Dashboard` 页面 `created` 生命周期内触发 | 保存到 Vuex `overview` |
| 列表查询 | `GET /code-blocks` | `CodeBlockTable` | 支持分页、筛选 |
| 获取详情 | `GET /code-blocks/{id}` | 详情页加载 | 返回 `codeBefore`、`codeAfter`、`annotationRange` |
| 生成迁移注解 | `POST /code-blocks/{id}/generate` | 详情页 & 批量操作 | 成功后刷新列表与概览 |
| 分类确认 | `POST /code-blocks/{id}/apply` / `ignore` | 详情页 | 根据人工决策将块标记为“已采纳”或“无需迁移” |
| 批量操作 | `POST /code-blocks/...` | `BatchToolbar` | 请求体传 `blockIds: string[]` |
| AI 建议（预留） | `GET /code-blocks/{id}/ai-suggestion` | `AISuggestionPanel` | 通过 feature flag 控制 |

### 5.2 API 封装建议

```js
// src/api/migration.js
import request from '@/api/request';

export const fetchOverview = (params) =>
  request.get('/migration/overview', { params });

export const fetchCodeBlocks = (params) =>
  request.get('/migration/code-blocks', { params });
// params.categories?: string[] => 分类筛选

export const fetchCodeBlockDetail = (id) =>
  request.get(`/migration/code-blocks/${id}`);

export const generateAnnotation = (blockId, annotationTemplate) =>
  request.post('/migration/code-blocks/generate', {
    blockIds: [blockId],
    annotationTemplate,
  });

export const applyCodeBlock = (blockId) =>
  request.post('/migration/code-blocks/apply', { blockIds: [blockId] });

export const ignoreCodeBlock = (blockId) =>
  request.post('/migration/code-blocks/ignore', { blockIds: [blockId] });

export const batchGenerate = (blockIds) =>
  request.post('/migration/code-blocks/generate', { blockIds });

export const batchApply = (blockIds) =>
  request.post('/migration/code-blocks/apply', { blockIds });

export const batchIgnore = (blockIds) =>
  request.post('/migration/code-blocks/ignore', { blockIds });
```

> `request` 实例建议复用现有 axios 封装，统一处理 Base URL `/api/v1`.

## 6. 数据同步与导航流程

1. **Dashboard 初次进入**
   - 触发 `fetchOverview` 与 `fetchCodeBlocks`。
   - 将 `overview.codeCategoryStats` 转换为筛选器选项。
2. **切换筛选或分页**
   - 更新 Vuex `filters`，重新拉取列表。
3. **批量操作**
   - 调用对应接口 → 成功提示 → 刷新列表 & `fetchOverview`。
4. **跳转详情**
   - 通过路由携带 `id`。
   - 详情页 `created` 钩子中调用 `fetchCodeBlockDetail`。
   - `ActionBar` 操作成功后触发父组件重新加载，同时通过事件总线或 Vuex 通知 Dashboard 列表更新。
