后端接口草案（Spring Boot + JDK 8）

> **核心原则：**
> - 所有**标签分类由后端统一定义并返回**
> - 前端仅负责**渲染**，不维护任何状态映射表
> - 支持未来动态新增分类、多项目不同策略

---

### 2. 查询代码块差异列表（带分页和筛选）

**接口路径**  
`GET /api/v1/migration/code-blocks`

**请求参数**
| 参数 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| `projectKey` | String | 是 | 项目标识 |
| `page` | Integer | 否 | 页码（默认 1） |
| `size` | Integer | 否 | 每页数量（默认 20） |
| `status` | String[] | 否 | 状态筛选（如 `unmigrated`, `migrated_with_annotation`） |
| `filePath` | String | 否 | 按文件路径模糊查询 |

**响应示例**

### 3. 批量生成迁移注解（1:1 迁移 + 添加注解）

**接口路径**  
`POST /api/v1/migration/code-blocks/generate`

**请求体**
```json
{
  "blockIds": ["cb_001", "cb_003", "cb_005"],
  "annotationTemplate": "/** MIGRATED: [source={file}, line={start}-{end}] */"
}
```

**响应**
```json
{
  "success": true,
  "message": "3 个代码块已成功生成迁移注解",
  "updatedBlocks": ["cb_001", "cb_003", "cb_005"],
  "newStatus": "migrated_with_annotation",
  "newStatusLabel": "已迁移",
  "newStatusColor": "blue"
}
```

> 💡 前端收到后可批量更新列表中对应项的 `status`、`statusLabel`、`statusColor`

## ✅ 前端（Vue2）使用建议

### 动态渲染标签
```vue
<template>
  <!-- 图表数据 -->
  <div v-for="cat in overview.codeCategoryStats" :key="cat.key">
    <span class="chart-label" :style="{ backgroundColor: cat.color }">
      {{ cat.label }} ({{ cat.percentage | percent }})
    </span>
  </div>

  <!-- 代码块状态标签 -->
  <table>
    <tr v-for="block in blocks" :key="block.id">
      <td>{{ block.filePath }}</td>
      <td>
        <span class="status-tag" :style="{ backgroundColor: block.statusColor }">
          {{ block.statusLabel }}
        </span>
      </td>
    </tr>
  </table>
</template>
```

### 状态筛选器
```js
// 从 overview.codeBlockStatusStats 生成筛选选项
computed: {
  filterOptions() {
    return this.overview?.codeBlockStatusStats.map(s => ({
      value: s.key,
      label: s.label,
      color: s.color
    }));
  }
}
```

## ✅ 总结：本次优化亮点

| 特性 | 实现方式 |
|------|----------|
| **标签完全由后端驱动** | 所有 `label`、`color`、`key` 由后端返回 |
| **前端无硬编码** | 无需 if/switch 判断状态 |
| **支持动态扩展分类** | 新增类型只需后端配置，前端自动适配 |
| **前后端职责清晰** | 后端管“是什么”，前端管“怎么画” |
| **未来兼容 AI 动态分类** | 如 AI 返回 `security_fix`，前端可直接渲染 |
