# **页面一：代码迁移总览仪表盘**  
**页面标题：** Dashboard - Project Overview  
**主题：** 代码迁移状态的总览、筛选与批量操作（以代码块为粒度）

---

## **1. 顶部标题区**

| **属性** | **内容** |
|---------|--------|
| **元素描述** | - 主标题：`代码迁移比较工具`（居左）<br>- 副标题：`新旧工程路径比较`<br>- 显示当前正在对比的新旧工程路径（如：`旧路径：/src/old-project` → `新路径：/src/new-project`） |
| **结构与风格要求** | - 固定在页面顶部的简洁 Header 栏<br>- 主副标题层级分明，字体加粗/颜色区分<br>- 工程路径以浅色小字显示，清晰可读 |
| **重点功能** | 快速确认当前对比的项目范围，提供上下文信息 |

---

## **2. 数据看板区**

| **属性** | **内容** |
|---------|--------|
| **元素描述** | 两张并排的图表卡片：<br><br>1. **代码迁移类别占比图**<br>   - 图表类型：环形图 或 圆形图<br>   - 分类维度：`已迁移`、`语法改造`、`适配改造`、`其他`、`未迁移`（标签由后端分析返回）<br>   - 数据单位：行数（LOC）占比 + 实际行数<br><br>2. **新代码提交占比图**<br>   - 图表类型：柱状图 或 仪表盘图<br>   - 指标：新系统代码中“新提交代码”所占比例（如：78%） |
| **结构与风格要求** | - 两张卡片等宽并列，占据页面主视觉区域<br>- 每张图表支持鼠标悬停，显示具体数值（百分比 + 行数）<br>- 图例清晰，颜色区分明显 |
| **重点功能** | 快速掌握整体迁移进度与新代码增长趋势，识别风险区域（如“未迁移”比例过高） |

---

## **3. 批量操作与筛选区**

| **属性** | **内容** |
|---------|--------|
| **元素描述** | 左右布局工具栏：<br><br>- **左侧：操作按钮组**<br>  - `批量生成`（主色）→ **当前语义：将选中的“未迁移”代码块 1:1 迁移并添加注解**<br>    - 示例格式：`/** MIGRATED: user login logic from OldSystem v1 */ ... 原始代码 ... /** MIGRATED-END */`<br>  - `批量应用`（次色）→ **当前语义：标记为“已生成”的代码块状态更新为“已应用”**（不触发远程 AI）<br>  - `批量忽略`（中性/警告色）→ 标记为无需处理<br><br>- **右侧：筛选器与搜索**<br>  - `文件名搜索框`：输入文件名关键字（忽略路径，支持模糊匹配）；回车或点击搜索后刷新列表<br>  - `类别筛选器`：筛选项为**代码块的迁移状态标签**（由后端返回），支持多选 |
| **结构与风格要求** | - 按钮使用颜色区分优先级与语义<br>- 工具栏布局清晰，支持操作反馈提示（如“正在生成迁移注解...”） |
| **重点功能** | 支持基于**代码块级别**的 1:1 迁移与状态管理，适配本地迁移流程 |

---

## **4. 文件与代码块差异列表区**

| **属性** | **内容** |
|---------|--------|
| **元素描述** | 高密度数据表格，按文件分组展示其下的**多个代码块差异项**：<br><br>1. **选择框（Checkbox）** + 表头处的**全选按钮**<br>2. **文件路径**：可折叠/展开（如 `/src/user/login.js`）<br>3. **代码块信息行**（子行）：<br>   - 显示行号范围（如 `L23-35`）<br>   - 显示简要代码摘要<br>   - **迁移状态标签**：由后端返回，如：<br>     - `未迁移`（红色）<br>     - `已迁移（带注解）`（蓝色）<br>     - `待本地AI处理`（橙色）<br>     - `已应用`（绿色）<br>   - **操作链接**：点击跳转至该代码块的**详情页**（页面二） |
| **结构与风格要求** | - 支持分页、排序（按状态、文件、行号）<br>- 文件名搜索框应支持即时清空、回车触发与 `Esc` 关闭建议列表<br>- 勾选后点击“批量生成”，前端显示加载条，完成后状态更新为“已迁移（带注解）”<br>- 不提供“导出”功能 |
| **重点功能** | 以**代码块为单位**管理迁移流程，新增按文件名快速定位能力，支持本地两步式迁移的阶段性状态追踪 |

# **页面二：代码差异详情页**  
**页面标题：** Detail Page - Code Diff  
**主题：** 单个代码块的差异查看与本地迁移操作

---

## **1. 顶部信息栏**

| **属性** | **内容** |
|---------|--------|
| **元素描述** | - “返回”按钮（或面包屑导航）<br>- 显示当前代码块所属文件及行号范围（如：`/src/user/auth.js`，`L45-67`） |
| **结构与风格要求** | - 简洁 Header，固定在顶部 |
| **重点功能** | 快速确认当前操作上下文 |

---

## **2. 核心操作区**

| **属性** | **内容** |
|---------|--------|
| **元素描述** | 三个操作按钮，居左排列：<br>- `生成` → **执行 1:1 迁移并添加标准注解**<br>  - 示例：`/** MIGRATED: [source=file, line=45-67] */ ... 代码 ... /** MIGRATED-END */`<br>- `应用` → **标记该代码块为“已应用”**（表示已由本地 AI Agent 处理完成）<br>- `忽略` → 标记为无需迁移 |
| **结构与风格要求** | - 按钮样式与总览页保持一致<br>- 支持禁用状态（如“生成”在已有注解时置灰） |
| **重点功能** | 支持本地迁移流程的两步操作：先生成带注解代码，再标记为已处理 |

---

## **3. 代码比对区**

| **属性** | **内容** |
|---------|--------|
| **元素描述** | 左右双栏并排的代码查看器（Side-by-Side Diff）：<br><br>- 左栏：旧系统原始代码（高亮差异块）<br>- 右栏：新系统当前代码（可能为空或部分存在）<br>- 显示行号<br>- 差异使用颜色高亮（红/绿）<br>- **内联显示迁移标签**（由后端返回），如：<br>  - `未迁移代码块`（红色）<br>  - `已添加迁移注解`（蓝色） |
| **结构与风格要求** | - 类似 Git Diff 风格，支持滚动同步<br>- 注解标签清晰可见 |
| **重点功能** | 直观展示迁移前后的差异，辅助人工审核 |

---

## **4. 生成结果显示区（未来扩展预留）**

| **属性** | **内容** |
|---------|--------|
| **元素描述** | - **当前状态：隐藏或置灰**<br>- **未来扩展说明**：当系统接入在线 AI API 后，此区域将动态显示 AI 生成的迁移建议代码<br>- 预留区域位置（代码比对区下方或三栏中间）<br>- 标题预留：`AI 迁移生成结果（预览）` |
| **结构与风格要求** | - 当前不渲染内容，保留 DOM 占位或通过配置开关控制显示<br>- 支持未来通过 feature flag 启用 |
| **重点功能** | 为未来集成远程 AI 建议生成能力预留 UI 位置，保持架构可扩展性 |

---

## ✅ **关键设计说明（适配内网 + 未来扩展）**

| **设计点** | **当前实现（内网）** | **未来扩展（AI API）** |
|-----------|----------------------|------------------------|
| **“生成”操作** | 1:1 迁移 + 添加标准注解 | 调用 AI API 生成改造后代码 |
| **“应用”操作** | 本地标记状态为“已应用” | 将 AI 生成结果写入文件 |
| **迁移建议展示** | 不显示 AI 建议区 | 启用“生成结果显示区” |
| **AI 分类标签** | 由后端静态规则或分析工具生成 | 可由 AI 模型动态预测 |
| **前端集成方式** | 无远程 AI 调用 | 通过配置开关启用 AI 模块 |

---

**建议后续开发策略：**
1. 当前阶段：前端完全依赖后端返回的**迁移状态标签**和**代码注解逻辑**
2. 后端可集成 **本地 AI Agent CLI 工具**，通过脚本扫描 `/** MIGRATED */` 注解块，按规则文件自动改造
3. 前端可通过“刷新状态”按钮，重新拉取本地 AI 处理后的结果
4. 未来可通过配置中心开启 `enableAIRecommendations: true` 来激活 AI 建议区
