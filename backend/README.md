# Code Compare Tool 后端重构框架

## 目标
- 以《codeCompareTool项目重构.md》设定的能力边界为基准，重建更模块化的后端骨架。
- 借鉴现有 `backend` 服务的成熟组件，明确依赖关系与扩展点。
- 为后续代码生成提供目录约定与模块设计文档。

## 模块结构
- **core：** 应用启动、配置装配、公共工具。
- **api：** REST 接口、入参校验、异常处理与 DTO 映射。
- **scanning：** 仓库/文件扫描、Git 增量对比、元数据缓存。
- **diff：** 差异聚合、快照缓存、块级聚合入口。
- **block：** 块抽取、比较、分类与迁移执行。
- **rules：** 标签与规则定义、装载与执行。
- **stats：** 仪表盘统计与报表聚合。
- **agent：** 第三方建议适配与 Mock 实现。
- **repository：** 元数据存储、结果快照与后续数据库演进。
